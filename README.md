# -Simulador-de-Vida-Financeira-em-Python
Este é um projeto desenvolvido para praticar os fundamentos da linguagem Python, focando em lógica de programação, manipulação de dados e interação com o usuário via terminal.

## 🚀 Funcionalidades
- **Controle de Saldo:** Início com saldo personalizado e atualização em tempo real.
- **Gestão de Renda:** Adição de valores com soma automática ao saldo.
- **Controle de Gastos:** Registro de compras com validação de saldo (impede gastos maiores que o saldo disponível).
- **Histórico de Transações:** Armazenamento de todas as atividades da sessão em uma lista para consulta posterior.
- **Tratamento de Erros:** Implementação de blocos `try/except` para evitar que o programa trave ao digitar valores inválidos.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.x
- **Conceitos Aplicados:**
  - Estruturas de repetição (`while`)
  - Condicionais (`if`, `elif`, `else`)
  - Manipulação de Listas (`.append()`)
  - Tratamento de Exceções (`try/except`)
  - Formatação de Strings (f-strings)

## 📖 Como executar o projeto
1. Certifique-se de ter o Python instalado.
2. Clone este repositório ou baixe o arquivo `simulador.py`.
3. Execute o comando no terminal:
   ```bash
   python simulador.py
